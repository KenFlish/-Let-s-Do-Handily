# [Let's Do] Handily

Cook Farm & Charm dishes directly in the world, using Diegesis. Inspired by Hands-On Delight. Work in progress.

Версия **0.5.0** переделывает доску, добавляет варенье Bakery и исправляет отображение кастрюль и жаровни в мире.

[Скачать JAR](releases/0.5.0/handily-neoforge-1.21.1-0.5.0.jar) · [Исходники и архив проекта](releases/0.5.0/)

## Установка

Minecraft **1.21.1**, Java **21**, NeoForge **21.1.253+**; сборка и проверки — **21.1.265**. Установите на клиент и сервер:

| Мод | Версия |
| --- | --- |
| [Let's Do] Handily | 0.5.0 |
| Farm & Charm | 1.1.29 |
| Diegesis | 1.0.0-beta.8 |
| Architectury API для NeoForge | 13.0.11 |

Foundation **1.0.7** уже вложен в Farm & Charm. Hands-On Delight и Farmer's Delight не обязательны. Перед обновлением уберите старый JAR Handily. Внутренний ID `handson_farm_charm` сохранён.

Необязательные интеграции: **Candlelight 2.1.15** и **Bakery 2.1.11**. Candlelight получает сцены сковородки и большого котла; его печи сохраняют обычный интерфейс. Bakery получает сцену `small_cooking_pot` для варенья. Совместный запуск проверяется с Hands-On Delight **1.4.0** и Farmer's Delight **1.3.4**.

## Управление

- **ПКМ** открывает сцену, **Shift + ПКМ** сохраняет штатное действие блока, **Esc** возвращает камеру. Инвентарь находится снизу, книга переносит один комплект недостающих ингредиентов.
- **Кастрюля:** возьмите ложку коротким щелчком или удерживайте ЛКМ и вращайте мышь. Без перемешивания готовка занимает **35 секунд**, с активным перемешиванием — около **23–35 секунд**. Без нагрева прогресс не идёт. Жидкость и ингредиенты видны снаружи ещё до первого перемешивания. У большого котла Candlelight крышка полностью убрана; ложка остаётся внутри и видна в обычном мире.
- **Миска:** вращайте штатный венчик круговыми движениями мыши.
- **Доска:** положите еду прямо на рабочую поверхность. Нож или тесак берётся с курсора либо из инвентаря; нажимайте по наклонным пунктирным линиям. Поддерживаются тесаки Farm & Charm и ножи из `c:tools/knife`. **Shift + ЛКМ** инструментом по пустой доске втыкает его в доску; обычный щелчок пустой рукой забирает его. Можно загрузить до **16** одинаковых продуктов для последовательной нарезки; каждый готовый продукт расходует один входной предмет.
- **Сборка на доске:** выкладывайте слои по рецепту, без ножа. Готовые сборки создаются автоматически, если они не являются началом более длинного рецепта; ЛКМ подтверждает сборку, ПКМ снимает верхний слой. Книга содержит вкладки блюд, нарезки и работы топором. Добавлены обычные пищевые крафты, включая возврат вёдер у торта. Выбранный в книге рецепт сохраняется в блоке и разрешает совпадающие рецепты разных модов.
- **Мясорубка:** вращайте рукоятку. Можно загрузить стопку сырья; Shift при выборе рецепта загружает несколько порций.
- **Печь:** положите ингредиенты и топливо, нажмите огниво. Используются штатные звуки поджигания и тушения. Камера остаётся перед печью.
- **Жаровня:** откройте крышку, выложите продукты и закройте. Готовка идёт с закрытой крышкой. Продукты расположены слоями без видимых ячеек; дно поднято над верхней гранью блока под жаровней. У сковородки Candlelight крышки нет.
- **Варенье Bakery:** добавляйте продукты вручную или через книгу и мешайте венчиком, когда варенье этого требует. Сохраняются штатные нагрев, сроки помешивания, пригорание, консистенция, выход, опыт и свойства варенья. Для разлива нужна пустая банка. Очистка уже готовящегося варенья уничтожает партию, как в Bakery.

Кастрюля и жаровня готовят без заранее вставленной посуды. Миска или другая тара из рецепта расходуется при получении порции. Пустые выходы скрыты. Ракурс доски и жаровни зависит от стороны подхода, при этом продукты остаются на настоящей рабочей поверхности.

Станции, книгу, Candlelight и Bakery можно отдельно отключить в `config/handson_farm_charm-common.toml`. Сервер проверяет действия игроков; используются родные рецепты и инвентари блоков.

## Сборка

Нужны JDK 21 и Python 3:

```text
python tools/fetch_dependencies.py
gradlew.bat build
```

На Linux/macOS: `./gradlew build`. Зависимости загружаются по URL и SHA-256 из `dependencies.lock.json`. Bakery скачивается для компиляции интеграции; без `-Pcompat` он не попадает в тестовый runtime и не нужен игроку. Все runtime-зависимости остаются отдельными модами.

JAR находится в `build/libs/`. `python tools/generate_assets.py` пересоздаёт сцены и переводы. `python tools/write_release_docs.py` упаковывает JAR, исходники и инструкцию в `dist/Handily-0.5.0/`.
