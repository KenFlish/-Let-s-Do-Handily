# [Let's Do] Handily

Cook Farm & Charm dishes directly in the world, with a 3D interface built on Diegesis. Inspired by Hands-On Delight. Work in progress.

Версия **0.4.0** добавляет нарезочную доску и сцены станций Candlelight, исправляет вылет сковородки и пропорции значков книги. Рамка по краям страниц убрана; модель и текстура обложки используются из Minecraft.

[Скачать JAR 0.4.0](releases/0.4.0/handily-neoforge-1.21.1-0.4.0.jar) · [Файлы сборки и исходники](releases/0.4.0/)

## Установка

Minecraft **1.21.1**, Java **21**, NeoForge **21.1.253+** (сборка и проверки на **21.1.265**). Установите на клиент и сервер:

| Мод | Версия |
| --- | --- |
| [Let's Do] Handily | 0.4.0 |
| Farm & Charm | 1.1.29 |
| Diegesis | 1.0.0-beta.8 |
| Architectury API для NeoForge | 13.0.11 |

Foundation **1.0.7** уже вложен в Farm & Charm. Hands-On Delight и Farmer's Delight не обязательны. Замените старый JAR Handily: одновременно две версии устанавливать нельзя. Внутренний ID `handson_farm_charm` сохранён для совместимости.

Необязательная интеграция проверена с **[Let's Do] Candlelight 2.1.15**, Hands-On Delight **1.4.0** и Farmer's Delight **1.3.4**. Для Candlelight доступны сковородка и большой котёл. Печи Candlelight сохраняют обычный интерфейс. Сковородка готовит без механики крышки жаровни.

## Управление

- **ПКМ** открывает сцену, **Shift + ПКМ** оставляет обычное действие блока, **Esc** возвращает камеру.
- Инвентарь находится снизу. Переносите ингредиенты на станцию или выбирайте рецепт в книге. Книга переносит недостающие ингредиенты одного комплекта, если хватает места и предметов.
- **Котёл:** вращайте мышью, удерживая ложку или взяв её коротким щелчком. Перемешивание ускоряет готовку до ×1,5; без нагрева ускорения нет.
- **Миска:** вращайте штатный венчик круговыми движениями мыши.
- **Доска, нарезка:** положите нож или тесак в боковой слот, затем ингредиент на доску. Нож следует за мышью; нажимайте ЛКМ по наклонным пунктирным линиям разреза. Кусочки расходятся по линии удара. Еда лежит по центру рабочей части доски Farm & Charm. Поддерживаются тесаки Farm & Charm и ножи из общего тега `c:tools/knife`, включая Farmer's Delight. Число ударов зависит от штатного рецепта и тесака; износ, опыт и побочные продукты сохраняются.
- **Доска, сборка:** уберите нож, выкладывайте ингредиенты по рецепту или перенесите их из книги. ЛКМ по доске либо кнопке сборки создаёт блюдо без ножа; ПКМ возвращает верхний ингредиент. Порядок слоёв и завершающий ингредиент сохраняются. Результаты нарезки и сборки доступны сбоку; оставшиеся результаты возвращаются при выходе, ингредиенты и нож остаются в блоке.
- **Мясорубка:** вращайте рукоятку мышью. Можно загрузить стопку сырья; Shift при выборе рецепта загружает несколько порций.
- **Печь:** положите ингредиенты и топливо, нажмите огниво. Это выпечка; переворачивать продукты не нужно.
- **Жаровня:** откройте крышку, добавьте ингредиенты и закройте. При открытой крышке приготовление приостанавливается.
- Котёл и жаровня готовят без заранее вставленной посуды. Для получения порции нужна подходящая миска или другая тара из рецепта.

Станции, книгу и интеграцию Candlelight можно отдельно отключить в `config/handson_farm_charm-common.toml`. Перемещение предметов и действия инструментов проверяет сервер. Моды продолжают использовать родные рецепты и инвентари станций.

## Сборка исходников

Нужны JDK 21 и Python 3. Зависимости скачиваются по URL и SHA-256 из `dependencies.lock.json`:

```text
python tools/fetch_dependencies.py
./gradlew build
```

На Windows: `gradlew.bat build`. Готовые JAR находятся в `build/libs/`. `python tools/generate_assets.py` пересоздаёт сцены и локализации; `python tools/write_release_docs.py` упаковывает текущую сборку и исходники в `dist/Handily-0.4.0/`.
