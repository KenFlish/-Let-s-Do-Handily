# [Let's Do] Handily

Cook Farm & Charm dishes directly in the world, using Diegesis. Inspired by Hands-On Delight. Work in progress.

Handily 0.6.3 brings Hands-On Delight motion to native Let's Do cookware: clear water, pouring and dissolving, stirring, vessel offers, direct inventory delivery, and cutting from every camera side.

[Скачать JAR](releases/0.6.3/handily-neoforge-1.21.1-0.6.3.jar) · [Исходники и архив проекта](releases/0.6.3/)

## Установка

Minecraft **1.21.1**, Java **21**, NeoForge **21.1.253+**; сборка и проверки — **21.1.265**. Установите на клиент и сервер:

| Мод | Версия |
| --- | --- |
| [Let's Do] Handily | 0.6.3 |
| Farm & Charm | 1.1.29 |
| Diegesis | 1.0.0-beta.8 |
| Architectury API для NeoForge | 13.0.11 |

Foundation **1.0.7** уже вложен в Farm & Charm. Hands-On Delight и Farmer's Delight не обязательны. Перед обновлением уберите старый JAR Handily. Внутренний ID `handson_farm_charm` сохранён; существующие миры и инвентари станций совместимы.

Необязательные интеграции: **Candlelight 2.1.15** и **Bakery 2.1.11**. Candlelight получает сцены сковородки и большого котла; его печи сохраняют обычный интерфейс. Bakery получает сцену `small_cooking_pot` для варенья; наполнение банок остаётся штатным. Совместный запуск проверяется с Hands-On Delight **1.4.0** и Farmer's Delight **1.3.4**.

## Управление

- **Посуда:** над готовой едой предлагается подходящая миска, тарелка или банка из инвентаря. ЛКМ выдаёт порцию прямо в инвентарь, Shift — доступную партию. Можно принести посуду на курсоре; даже последняя миска оставляет результат в инвентаре. Если места или посуды нет, продукты и тара не расходуются. Старая посуда во внутреннем слоте станции и воронки продолжают работать.
- **Кастрюля:** в пустой посуде уже видна чистая вода. Твёрдые ингредиенты окрашивают её постепенно при перемешивании; молоко меняет основу во время наливания. Возьмите ложку коротким щелчком либо удерживайте ЛКМ и ведите мышь по кругу. Ложка наклоняется вслед за рукой, продукты плавно плавают и обходят её. Нужен нагрев.
- **Возврат ингредиентов:** щелчок по плавающему продукту забирает его. Для сахара, яйца и налитых ингредиентов появляется полупрозрачный предпросмотр над водой; ПКМ с пустым курсором возвращает последний из них в инвентарь. Полный инвентарь оставляет весь предмет в кастрюле.
- **Сборка:** неупорядоченный рецепт принимает любой подходящий первый ингредиент — например, сыр для салата Candlelight. Миска завершает блюдо. Упорядоченные рецепты сохраняют родной порядок. Вкладка сборки выбирает сборку и для нарезаемых компонентов; без выбора такой продукт начинает нарезку. ЛКМ завершает одну порцию, Shift — партию; ПКМ возвращает верхний слой. Результат и возвратная тара сразу попадают в инвентарь.
- **Старые выходы доски:** скрытые выходные ячейки прежних версий переносятся в инвентарь при открытии и во время работы. То, что не поместилось, сохраняется в блоке.
- **Bakery:** очистка выполняется ЛКМ по настоящей деревянной ручке с пустым курсором. Ручка обводится при наведении; подсказка предупреждает об уничтожении партии. Банки наполняются через предложение над вареньем, по одной или с Shift.
- **Мясорубка и чайники:** сохраняют обычное взаимодействие исходных модов, без сцен Handily.

- **ПКМ** открывает сцену, **Shift + ПКМ** сохраняет штатное действие блока, **Esc** возвращает камеру. Инвентарь находится снизу, книга переносит один комплект недостающих ингредиентов.
- **Предметы:** при перетаскивании виден один плоский значок предмета и один счётчик; нож на доске и предпросмотр размещения сохранены.

- **Миска:** вращайте штатный венчик круговыми движениями мыши.
- **Доска:** нарезка как в Hands-On Delight. Сервер выбирает число и положение разрезов, режется только следующий разрез, последний удар дорезает партию до **16** предметов. Тесак и нож требуют одинакового числа ударов — числа из рецепта; топор для снятия коры по-прежнему делает два удара. Нож или тесак берётся с курсора либо из инвентаря; **Shift + ЛКМ** инструментом по пустой доске втыкает его, обычный щелчок пустой рукой забирает. Раскладка предметов, вкладки книги и каталог рецептов сохранены.
- **Печь:** положите ингредиенты и топливо, нажмите огниво. Используются штатные звуки поджигания и тушения. Только печь сохраняет фиксированный передний ракурс.
- **Жаровня:** откройте крышку, выложите продукты и закройте. Готовка идёт с закрытой крышкой. Продукты расположены слоями без видимых ячеек; дно поднято над верхней гранью блока под жаровней. У сковородки Candlelight крышки нет.
- **Варенье Bakery:** добавляйте продукты вручную или через книгу и мешайте венчиком, когда варенье этого требует. Сохраняются штатные нагрев, сроки помешивания, пригорание, консистенция, выход, опыт и свойства варенья. Для разлива нужна пустая банка. Очистка уже готовящегося варенья уничтожает партию, как в Bakery.

Сторона камеры выбирается до начала приближения: доска, жаровня, сковородка и кастрюля сразу открываются со стороны игрока, в том числе при переходе от соседней станции. Поворот камеры и элементов интерфейса отделён от модели блока: кастрюля и мясорубка сохраняют положение в мире. Предметы на курсоре, в котле и на доске поворачиваются к камере, а не к передней стороне блока. Блоки перед камерой больше не вырезаются из мира: у всех сцен Handily отключено скрытие блоков.

Кастрюля и жаровня готовят без заранее вставленной посуды. Миска или другая тара из рецепта расходуется при получении порции. Пустые выходы скрыты.

Станции, книгу, Candlelight и Bakery можно отдельно отключить в `config/handson_farm_charm-common.toml`. Сервер проверяет действия игроков; используются родные рецепты и инвентари блоков.

## Сборка

Нужны JDK 21 и Python 3:

```text
python tools/fetch_dependencies.py
gradlew.bat build
```

На Linux/macOS: `./gradlew build`. Зависимости загружаются по URL и SHA-256 из `dependencies.lock.json`. Bakery скачивается для компиляции интеграции; без `-Pcompat` он не попадает в тестовый runtime и не нужен игроку. Все runtime-зависимости остаются отдельными модами.

JAR находится в `build/libs/`. `python tools/generate_assets.py` пересоздаёт сцены и переводы. `python tools/write_release_docs.py` упаковывает JAR, исходники и инструкцию в `dist/Handily-0.6.3/`.
