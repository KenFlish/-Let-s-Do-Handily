# [Let's Do] Handily

Cook Farm & Charm dishes directly in the world, using Diegesis. Inspired by Hands-On Delight. Work in progress.

Версия **0.6.2** переделывает перемешивание: конец штатной ложки следует за курсором, рукоятка наклоняется, ингредиенты плавают с инерцией и обходят ложку. Сахар и другие твёрдые ингредиенты видны и доступны для извлечения. Мясорубка и чайники по-прежнему используют обычное взаимодействие исходных модов, без 3D-сцен Handily.

[Скачать JAR](releases/0.6.2/handily-neoforge-1.21.1-0.6.2.jar) · [Исходники и архив проекта](releases/0.6.2/)

## Установка

Minecraft **1.21.1**, Java **21**, NeoForge **21.1.253+**; сборка и проверки — **21.1.265**. Установите на клиент и сервер:

| Мод | Версия |
| --- | --- |
| [Let's Do] Handily | 0.6.2 |
| Farm & Charm | 1.1.29 |
| Diegesis | 1.0.0-beta.8 |
| Architectury API для NeoForge | 13.0.11 |

Foundation **1.0.7** уже вложен в Farm & Charm. Hands-On Delight и Farmer's Delight не обязательны. Перед обновлением уберите старый JAR Handily. Внутренний ID `handson_farm_charm` сохранён; существующие миры и инвентари станций совместимы.

Необязательные интеграции: **Candlelight 2.1.15** и **Bakery 2.1.11**. Candlelight получает сцены сковородки и большого котла; его печи сохраняют обычный интерфейс. Bakery получает сцену `small_cooking_pot` для варенья; наполнение банок остаётся штатным. Совместный запуск проверяется с Hands-On Delight **1.4.0** и Farmer's Delight **1.3.4**.

## Управление

- **ПКМ** открывает сцену, **Shift + ПКМ** сохраняет штатное действие блока, **Esc** возвращает камеру. Инвентарь находится снизу, книга переносит один комплект недостающих ингредиентов.
- **Предметы:** при перетаскивании виден один плоский значок предмета и один счётчик; нож на доске и предпросмотр размещения сохранены.
- **Посуда:** отдельного слота для мисок больше нет. Посуда, уже лежащая в станции (слот 6), остаётся во внутреннем инвентаре, воронки продолжают работать. Нажмите подходящей посудой на курсоре по готовому блюду — получите одну порцию; если посуда закончилась, блюдо займёт место на курсоре, иначе уйдёт в инвентарь. **Shift + ЛКМ** забирает максимум порций, используя посуду из инвентаря и запас станции. **ПКМ** подходящей посудой по станции снаружи сцены выдаёт одну порцию без открытия интерфейса; последняя посуда в руке заменяется блюдом. Сервер проверяет готовность, посуду, расстояние и место; при нехватке места ничего не расходуется.
- **Кастрюля:** возьмите ложку коротким щелчком или удерживайте ЛКМ и вращайте мышь. Без перемешивания готовка занимает **35 секунд**, с активным перемешиванием — около **23–35 секунд**. Без нагрева прогресс не идёт. Жидкость видна снаружи сразу после добавления ингредиентов, без первого перемешивания; в мире и в сцене используется одна поверхность, один цвет и одна высота. У большого котла Candlelight крышка полностью убрана, форма взаимодействия и столкновения соответствует открытому котлу: стенки, дно и ручки.
- **Миска:** вращайте штатный венчик круговыми движениями мыши.
- **Содержимое котла:** сахар, мука и остальные твёрдые ингредиенты больше не скрываются. Щёлкните по плавающему предмету, чтобы забрать его. **ПКМ по жидкости с пустым курсором** возвращает в инвентарь последний налитый ингредиент, если есть место; это не выдача готового блюда.
- **Доска:** нарезка как в Hands-On Delight. Сервер выбирает число и положение разрезов, режется только следующий разрез, последний удар дорезает партию до **16** предметов. Тесак и нож требуют одинакового числа ударов — числа из рецепта; топор для снятия коры по-прежнему делает два удара. Нож или тесак берётся с курсора либо из инвентаря; **Shift + ЛКМ** инструментом по пустой доске втыкает его, обычный щелчок пустой рукой забирает. Раскладка предметов, вкладки книги и каталог рецептов сохранены.
- **Сборка на доске:** слои кладутся снизу вверх, первый слой — основа блюда, каждый слой должен подходить к блюду. Партия собирается раундами: несколько одинаковых слоёв дают несколько блюд, остатки (ведро, бутылка) возвращаются игроку. Выбранное в книге блюдо собирается автоматически; **ЛКМ** завершает сборку, **ПКМ** снимает верхний слой целиком. Финальные анимации HOD: PRESS, SANDWICH, TOSS, ROLL, SKEWER, KNEAD, ARRANGE, SHAPE, FREEZE.
- **Мясорубка:** обычное взаимодействие Farm & Charm, без сцены Handily и без изменения штатной скорости.
- **Печь:** положите ингредиенты и топливо, нажмите огниво. Используются штатные звуки поджигания и тушения. Только печь сохраняет фиксированный передний ракурс.
- **Жаровня:** откройте крышку, выложите продукты и закройте. Готовка идёт с закрытой крышкой. Продукты расположены слоями без видимых ячеек; дно поднято над верхней гранью блока под жаровней. У сковородки Candlelight крышки нет.
- **Варенье Bakery:** добавляйте продукты вручную или через книгу и мешайте венчиком, когда варенье этого требует. Сохраняются штатные нагрев, сроки помешивания, пригорание, консистенция, выход, опыт и свойства варенья. Для разлива нужна пустая банка. Очистка уже готовящегося варенья уничтожает партию, как в Bakery.

Сторона камеры выбирается до начала приближения: доска, жаровня, мясорубка, сковородка и кастрюля сразу открываются со стороны игрока, в том числе при переходе от соседней станции. Поворот камеры и элементов интерфейса отделён от модели блока: кастрюля и мясорубка сохраняют положение в мире. Предметы на курсоре, в котле и на доске поворачиваются к камере, а не к передней стороне блока. Блоки перед камерой больше не вырезаются из мира: у всех сцен Handily отключено скрытие блоков.

Кастрюля и жаровня готовят без заранее вставленной посуды. Миска или другая тара из рецепта расходуется при получении порции. Пустые выходы скрыты.

Станции, книгу, Candlelight и Bakery можно отдельно отключить в `config/handson_farm_charm-common.toml`. Сервер проверяет действия игроков; используются родные рецепты и инвентари блоков.

## Сборка

Нужны JDK 21 и Python 3:

```text
python tools/fetch_dependencies.py
gradlew.bat build
```

На Linux/macOS: `./gradlew build`. Зависимости загружаются по URL и SHA-256 из `dependencies.lock.json`. Bakery скачивается для компиляции интеграции; без `-Pcompat` он не попадает в тестовый runtime и не нужен игроку. Все runtime-зависимости остаются отдельными модами.

JAR находится в `build/libs/`. `python tools/generate_assets.py` пересоздаёт сцены и переводы. `python tools/write_release_docs.py` упаковывает JAR, исходники и инструкцию в `dist/Handily-0.6.2/`.
