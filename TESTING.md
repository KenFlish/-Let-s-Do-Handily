# Проверка Handily 0.5.0

Среда: Java 21, Minecraft 1.21.1, NeoForge 21.1.265, Farm & Charm 1.1.29, Diegesis 1.0.0-beta.8, Architectury 13.0.11, вложенный Foundation 1.0.7.

## Сервер

```text
gradlew.bat runGameTestServer -PgameTests -Pcompat --offline
gradlew.bat runGameTestServer -PgameTests --offline
```

Первый вариант проверен с Candlelight 2.1.15, Bakery 2.1.11, Hands-On Delight 1.4.0 и Farmer's Delight 1.3.4: **13 из 13 GameTest прошли**. Второй запускается только с обязательными модами: **13 из 13 прошли**, включая пять проверок, которые явно пропускают действия с отсутствующими необязательными модами.

Покрытые сценарии:

- Сковородка Candlelight выдерживает штатные серверные тики; свойства крышки жаровни ей не навязываются.
- Большой котёл Candlelight использует настоящий инвентарь; крышка полностью убрана, жидкость появляется до первого движения ложки. Печам Candlelight сцены не регистрируются.
- Доска режет тесаком Farm & Charm и ножом Farmer's Delight с родным порогом ударов, износом и побочными продуктами. Неверные координаты и повторный удар в тот же тик отклоняются.
- Сборка проверяется для всех доступных штатных рецептов доски: порядок, завершающий ингредиент и пищевые компоненты сохраняются. Совпадающие рецепты Bakery/Candlelight разрешаются по выбору из книги.
- Отсутствие завершающего ингредиента отменяет перенос целиком.
- Еда с курсора помещается на доску без установленного ножа. После обработки одного предмета очередь из трёх содержит два; взятый с курсора нож возвращается с одним списанным использованием. Очередь сохраняется в родном NBT.
- Инструмент можно воткнуть в пустую доску и сохранить. Заполненный выход останавливает нарезку без расхода сырья.
- Обычный рецепт торта создаёт один торт и возвращает три ведра.
- Реальная готовка кастрюли без перемешивания завершается ровно на **700-м тике**. До этого выхода нет. Без нагрева прогресс равен нулю. Выдача порции требует одну настоящую ёмкость. Активное перемешивание завершает рецепт примерно за **467 тиков**, сохраняя ограничение ×1,5.
- Bakery начинает штатный рецепт из книги, не готовит без нагрева, требует помешивания после 160 тиков и не получает его от простого открытия сцены. Проверенное движение мышью сбрасывает штатный запрос помешивания. Разлив выдаёт родной результат и расходует одну пустую банку.

`KitchenGameTests.java` содержит исторические проверки версии 0.1.0 и исключён по умолчанию. Его старые результаты не подтверждают поведение текущей версии.

## Клиент

```text
gradlew.bat runClient -PvisualTests -PcompatVisual -Pcompat --offline
```

Используется отдельный тестовый мир `run-client/saves/Showcase`. Сценарий берёт предмет через API инвентаря и отправляет настоящий клик экрану Diegesis над доской. Проверяется, что три ингредиента остались в блоке, а курсор опустел. При повторном открытии с восточной стороны проверяется выбранный ракурс `approach_1`.

Снимки в `run-client/screenshots/handily-050-*.png` охватывают доску, сковородку, пустое дно котла Candlelight, выкладку в жаровне, жаровню в обычном мире, жидкость без перемешивания, варенье и доску с другого ракурса. Отдельный снимок показывает котёл Candlelight без крышки в обычном мире. Пустые выходные слоты скрыты; постоянная надпись сверху у варенья удалена.

Тестовые классы и миры не входят в релизный JAR. Папка основной пользовательской сборки не изменяется.

## Границы проверки

Автоматические проверки и снимки не заменяют длительную игру с двумя сетевыми клиентами, всеми модами пользовательской сборки, шейдерами и всеми сочетаниями соседних блоков. Полный перебор рецептов кастрюли и жаровни с бонусами костюма повара не выполнялся. Механика выдачи использует штатные рецепты и предметы; возвращаемые при закрытии сцены предметы обслуживает Diegesis.

После последней просьбы крышка Candlelight полностью удалена, ложка закреплена внутри. Финальный JAR после этой правки собран и прошёл 13 серверных проверок; повторный визуальный запуск этой последней правки не выполнялся. Ранее сохранённые снимки относятся к промежуточным клиентским проверкам.
